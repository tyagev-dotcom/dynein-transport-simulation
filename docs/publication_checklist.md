# Publication Checklist

Before making this repository public:

- Confirm the exact manuscript title, author list, DOI, and preferred citation.
- Replace `CITATION.cff.template` with a finalized `CITATION.cff`.
- Choose an open-source license with the PI/institution and replace `LICENSE.md`.
- Confirm whether the original final project script in `reference/` should remain public.
- Decide whether stochastic seeds should be exposed as command-line parameters for exact reproducibility.
- Confirm that generated outputs are examples only and not required as primary manuscript data.
- Run each simulation variant on the intended platform and record compiler/version information.
- Check that no local paths, private notes, PDFs, executables, object files, or manuscript drafts are staged in git.
